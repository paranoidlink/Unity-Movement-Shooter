# Unity Movement Shooter

The C# scripts from my final university project: a first-person shooter focused heavily on movement mechanics.

The project was built in Unity and explored combining fast movement systems with first-person shooting and enemy behaviour.

## Movement

The project includes systems for:

- Dashing
- Sliding
- First-person camera control
- Player movement states

## Combat

The scripts include:

- Player shooting
- Weapon handling
- Enemy AI
- Enemy projectiles
- Enemy spawning

The project also uses physics and raycasting for parts of the movement and combat systems.

## Technologies

- Unity
- C#

## Project Context

This repository contains the scripts from my university final project rather than a complete packaged game.

It is preserved as an example of my earlier experience building gameplay systems and working with Unity's component-based architecture.
